# Changelog

## 0.1.0

Initial prototype of Origrami, a self-hosted messenger.

- End-to-end encrypted text chats with private rooms and invitations.
- Conversation search, drafts and connection/message status.
- Account requests with administrator approval and individual or bulk decisions.
- User, admin and protected superuser roles, with account management, a registration blocklist and an activity log.
- CPU, memory and disk statistics with superuser-controlled access for admins.
- Black/gold and burgundy themes with a responsive chat interface.
- Container-based setup, builds, tests and live development with optional local test accounts.

Device verification, key recovery and media sending are not yet available. See the [security model](SECURITY.md) for current limitations and the [roadmap](docs/roadmap.md) for planned development.
